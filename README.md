
📡 DataPulse-AI  
Real-time IoT dashboard to securely store, monitor, control, analyze, and forecast sensor data with live plotting and AI-driven insights.

🚀 Features

• 🔐 Secure JWT authentication

• 📥 Live IoT data logging

• 🧭 Monitor individual sensors

• 📊 Real-time interactive plots

• 🧠 Personal AI data assistant

• 📅 Add / delete / manage sensor logs

• 📈 Forecasting, analytics, and statistics

• 🛰 Remote control for IoT devices

• 🛰 OTP based logging 

------------------------------------------------------------

💡 Highlights
✔ Complete IoT data cycle: Log → Store → Visualize → Analyze → Control  
✔ Secure and scalable architecture  
✔ Real-time visual feedback
